
# Dataset

This project uses the IBM Telco Customer Churn dataset.

## Download

Dataset source:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Download the CSV and place it in this folder with the filename:

WA_Fn-UseC_-Telco-Customer-Churn.csv

Expected local path:

data/WA_Fn-UseC_-Telco-Customer-Churn.csv

The CSV is excluded from this Git repository. Please obtain it from the original dataset source and follow its licence terms.
